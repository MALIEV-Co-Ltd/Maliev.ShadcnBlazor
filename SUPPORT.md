# Support

Use GitHub Discussions for installation questions, component composition, and
design-system guidance. Use GitHub Issues for reproducible defects and focused
feature proposals.

When reporting a defect, include:

- The Maliev.ShadcnBlazor, .NET, browser, and MudBlazor versions.
- A minimal Razor reproduction.
- Expected and actual behavior.
- Relevant console output or an accessible screenshot.
- Whether the issue changes in dark mode, RTL, forced colors, reduced motion,
  or at 200% zoom.

Security vulnerabilities must use the private process in [SECURITY.md](SECURITY.md).
Do not disclose sensitive security details in Discussions or Issues.
