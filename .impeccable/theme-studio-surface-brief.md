# Theme Studio surface brief

- Scope: `/theme`; an operate-and-experience surface for evaluating a portable Blazor theme against realistic component compositions.
- Audience: Blazor developers comparing theme behavior before exporting or installing it.
- Job: scan a stable deck of realistic workflows, observe live component states, select a reviewed preset, inspect advanced settings, and export an exact reproducible theme.
- Direction: centered runway with the universal documentation app bar, a package Sidebar, a two-column counter-scrolling desktop canvas, and one natural-scroll mobile column.
- Memorable moment: two stable card tracks move in opposite directions while actual component states progress on a calm staggered timeline; touching any part of the preview pauses it.
- Approved desktop comp: `.impeccable/mocks/theme-studio-approved-direction-desktop.png`.
- Approved mobile comp: `.impeccable/mocks/theme-studio-approved-direction-mobile.png`.
- Constraints: card content and order never change on Shuffle; typography and icons are preview-scoped; motion is pausable and reduced-motion-safe; mobile never auto-scrolls; no raw color-token editor in the primary workflow; no component-catalog duplication.
- Supporting seams: shared documentation app bar, stable CodeBlock toolbar, bounded Message Scroller, and licensed optional icon companion packages.
